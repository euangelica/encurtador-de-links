# 🔗 Encurtador de Links

> Um site encurtador de links moderno, responsivo e funcional, desenvolvido com tecnologias web fundamentais para praticar lógica de programação, consumo de APIs e manipulação do DOM.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando:
* **HTML5** (Estruturação semântica da página)
* **CSS3** (Estilização personalizada, responsividade e design moderno)
* **JavaScript (Vanilla)** (Lógica de requisições, manipulação dinâmica e área de transferência)
* **TinyURL API** (Serviço externo para conversão e encurtamento das URLs)

---

## 💡 Funcionalidades

- **Encurtamento Instantâneo:** Insira qualquer URL longa e gere um link curto rapidamente.
- **Botão Copiar com Um Clique:** Copie o link encurtado diretamente para a área de transferência com feedback visual dinâmico.
- **Design Responsivo:** Adaptado para diferentes tamanhos de tela (computadores, tablets e celulares).
